# Security Policy

## Reporting Security Issues

If you find a security issue in DXaudit, do not publish technical details publicly before contacting the project owner.

Please include:

- application version,
- Windows version,
- issue description,
- reproduction steps,
- whether the issue exposes private data or allows unexpected behavior.

## Security Model

DXaudit is a defensive tool. The application should not collect passwords, cookies, browser history, document contents, emails, photos, or private files.
