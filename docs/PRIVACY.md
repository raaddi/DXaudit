# Privacy

## Data Collected

The application collects local technical data required for workstation auditing:

- Windows version, build, architecture, and uptime,
- computer model, CPU, RAM, disks, and free space,
- Defender, firewall, Windows Update, BitLocker, UAC, RDP, and SMBv1 status,
- local users and administrators,
- installed software and startup entries,
- basic local network information and local listening ports,
- backup, sync, and restore point indicators,
- selected system event summaries,
- optionally, public domain records.

## Data Not Collected

The application does not collect passwords, tokens, cookies, browser history, document contents, emails, photos, or private files.

## Storage

Reports are stored locally on the computer where the audit is run. The MVP version does not automatically upload reports to the internet.

## Privacy Mode

Privacy mode masks hostname, username, domain, IP address, local paths, and serial numbers.

## Limitations

The report is not a penetration test and is not a guarantee of complete security. Some results may depend on administrator privileges and local Windows configuration.
