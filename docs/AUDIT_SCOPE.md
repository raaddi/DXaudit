# Audit Scope

DXaudit is a defensive and administrative tool. Its purpose is to quickly assess a local Windows workstation and generate both a technical report and a readable summary.

## Audit Areas

- System and hardware.
- Local security.
- Microsoft Defender.
- Windows Firewall.
- Windows Update.
- BitLocker.
- Local accounts and administrators.
- Disks and free space.
- Performance.
- Startup entries.
- Installed software.
- Local network.
- Remote access and VPN.
- Browsers and extensions.
- Backup and data loss risk.
- Event Log.
- Printers and devices.
- Workstation readiness.
- Optionally, domain and email records.

## Out Of Scope

The application does not run exploits, password cracking, security bypasses, keylogging, persistence, process hiding, aggressive network scanning, automatic system repairs, or private file analysis.

## Required Permissions

The audit can run without administrator privileges, but more complete results are available when the application is run as administrator.
